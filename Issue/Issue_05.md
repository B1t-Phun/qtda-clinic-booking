# BÁO CÁO CÔNG VIỆC – ISSUE #5

**Tên công việc:** Khởi tạo project Next.js và kết nối Supabase  
**Dự án:** ClinicCare  
**Người thực hiện:** Đỗ Lê Viết Tài  
**Vai trò:** Project Manager + Tech Lead

## 1. Mục tiêu

Khởi tạo môi trường phát triển ứng dụng Web ClinicCare bằng Next.js và thiết lập kết nối với Supabase PostgreSQL.

## 2. Công việc thực hiện

- Khởi tạo project Next.js sử dụng TypeScript và App Router.
- Cài đặt các thư viện Supabase cần thiết.
- Tạo project Supabase phục vụ phát triển.
- Cấu hình biến môi trường kết nối.
- Tạo Supabase client trong Next.js.
- Kiểm tra khả năng truy vấn dữ liệu từ Supabase.
- Quản lý mã nguồn bằng Git và GitHub.

## 3. Công nghệ sử dụng

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Git và GitHub

## 4. Kết quả cần đạt

- Project Next.js chạy thành công trên môi trường local.
- Supabase project được khởi tạo.
- Next.js có thể truy vấn dữ liệu từ Supabase.
- Mã nguồn được push lên branch `feature/setup-nextjs-supabase`.
- Pull Request được tạo để nhóm review.

## 5. Minh chứng

- Ảnh giao diện Next.js chạy local.
- Ảnh Supabase Dashboard.
- Ảnh kết quả kiểm tra kết nối.
- Commit và Pull Request trên GitHub.

**Trạng thái:** Cập nhật sau khi thực hiện và kiểm thử.
